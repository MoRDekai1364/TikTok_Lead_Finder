# Owner Checklist (Phase 0)

This checklist tracks items requiring confirmation, sign-off, or ongoing curation by the project owner. Items not yet signed off by the owner are explicitly deferred with safe local-only defaults so implementation can proceed without blocking.

| # | Item | Status | Current Resolution / Default | Action Required from Owner |
| --- | --- | --- | --- | --- |
| 1 | Partner fact-checker tool export format | Deferred (Safe Default Active) | Importer supports plain newline-delimited URLs/video IDs and UTF-8 CSV/TSV/semicolon files with automatic detection of `url`, `link`, `video_url`, `id`, or `video_id` columns (plus positional single-column lists). | Confirm exact column header names or sample export from the team's partner tool and adjust if custom fields exist. |
| 2 | Employer approval for tool and data handling | Deferred (Owner Sign-off Pending) | All media, transcripts, OCR, claims, and SQLite databases remain strictly on localhost (`data/`). Cloud LLM and cloud APIs default to `cloud_enabled = false`. Media retention defaults to 7 days (`retention_days = 7`). | Obtain written employer/DPO sign-off before connecting institutional workflows or enabling optional cloud providers. |
| 3 | Unofficial TikTok discovery risk & Terms of Service | Deferred (Owner Sign-off Pending) | Hard technical boundaries enforced: zero login, zero token extraction, zero CAPTCHA solving, zero IP/fingerprint spoofing, strict 12 req/min rate limit, and automatic circuit breaker (5 failures -> 30 min cooldown). Automated discovery defaults to off until Phase 1 spike evaluation and owner confirmation; paste-a-link and partner-export import always work. | Confirm acceptable organizational risk posture before enabling scheduled automated discovery in production. |
| 4 | Gemini API free-tier terms for organizational use | Deferred (Cloud Off by Default) | `cloud_enabled = false` in `config/default.toml`. UI displays an explicit data-flow and reviewer notice before cloud providers can be enabled, and only text (never audio or video) is ever transmitted. | Verify current Google AI Studio / Gemini API terms for commercial/organizational fact-checking use (or use a paid billing project where data is not used for model training) before turning `cloud_enabled` on. |
| 5 | 30–50 Bulgarian seed keywords/hashtags & creator watchlist | Answered with Starter Set (Owner Editable) | 40 Bulgarian public-interest keywords and hashtags across elections, economy, health, institutions, energy, security, and viral-claim markers are preloaded in `config/seeds.bg.toml`. Creator watchlist starts empty and is editable in UI and CLI. | Review `config/seeds.bg.toml` (or the Seeds & Creators screens in the UI) and add/remove team-specific topics and watched accounts. |
| 6 | Create Git repository | Completed | Initialized Git repository at workspace root with `.gitignore` excluding secrets, `.env`, databases, media, caches, models, and build artifacts. | Optionally add a private remote (`git remote add origin <url>`). |
| 7 | Install Rust, Node, `ffmpeg`, and `yt-dlp` | Completed | Verified on Windows host: `rustc 1.99.1`, `cargo 1.99.1`, `node v26.8.1`, `npm 11.19.0`, `yt-dlp 2026.10.21`, `ffmpeg 9.0.1` / `ffprobe`. | None. |
